# The Psychonaut Bookworm — Research & Learning Library

Psychonaut Bookworm is an independent research and learning library indexing 1,399 editorial objects across psychedelic literature, with source visibility, rights-review notes, and a saved research qu

**Live:** https://psychonaut-bookworm.vercel.app

## Repository contents

`api`, `governance.html`, `index.html`, `provenance`, `robots.txt`, `sitemap.xml`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
